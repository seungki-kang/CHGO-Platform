# Start Here

This ZIP contains one working folder: `CHGO-Platform`.

1. Extract the ZIP at `D:\CHGO\Repository\`.
2. Open `D:\CHGO\Repository\CHGO-Platform\` as the repository root.
3. Read `STRUCTURE_GUIDE.md` before adding or moving files.
4. Use `registry/REPOSITORY_STRUCTURE_REGISTRY_1.0.csv` to choose the correct destination.
5. Run `tools/update-foundation/validation/validate_organized_repository.py` after structural changes.

Do not merge older full repository folders or nested ZIP files into this root. Keep the uploaded `Repository.zip` separately as the original backup.
